## 🚀 How to Run Locally

You can simply open [`index.html`](file:///c:/Users/abhiram/Desktop/portfolio%20site/index.html) directly in any web browser by double clicking it.

Alternatively, you can run a local server:
```bash

```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
